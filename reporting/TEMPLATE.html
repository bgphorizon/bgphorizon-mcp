Terms used in this report
BGP
The internet’s routing system. Networks use it to advertise which blocks of addresses they can deliver traffic for.
AS / AS number
Autonomous System. A numbered network under one administration, written AS54994.
Origin AS
The network that claims to hold the addresses. A prefix normally has exactly one.
Prefix
A block of addresses, written 153.43.253.0/24. A /24 is 256 addresses; a /16 is 65,536.
MOAS
Multiple Origin AS. Two networks announcing the same prefix at the same time.
Withdrawal
A message saying a route is no longer available. A burst of withdrawals means part of the internet briefly had no path to those addresses.
RPKI / ROA
Signed records stating which network may originate which prefix, so routers can reject announcements that do not match.
IRR
Internet Routing Registry. A published database of intended routes that providers use to build filters. Not cryptographically verified; stale entries persist.
